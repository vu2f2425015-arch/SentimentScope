help_outline Platform Architecture & Methodology FAQ

Key technical specifications, classification heuristics, and keyboard navigation.

Documentation
category 3-Class Sentiment Taxonomy (Positive, Neutral, Negative) expand_more

SentimentScope evaluates inputs across three distinct classes: Positive (favorable sentiment, satisfaction, endorsements), Neutral (informational, queries, balanced statements), and Negative (criticism, bugs, dissatisfaction).

Unlike binary classifiers that force ambiguous text into positive or negative extremes, the ternary model accurately models real-world social discourse.

balance Neutral Fallback Heuristics expand_more

When classification probability margins between classes fall below an ambiguity threshold, or when stopword-filtered content is too sparse to establish polar sentiment, the engine assigns Neutral as a safety fallback.

This prevents false positives on factual statements, URLs, or uninformative boilerplate text.

trending_up Decision Threshold Calibration expand_more

Probabilities from the underlying scikit-learn Logistic Regression / LinearSVC classifier are calibrated via Platt scaling / softmax cross-entropy. Threshold adjustments counteract class imbalance in training distributions, boosting minority class recall.

bolt Processing Latency & Caching Architecture expand_more

Single text predictions execute sub-15ms using vectorized TF-IDF n-gram pipelines. Database reads utilize SQLite WAL mode with mutex connection reuse, and rolling telemetry queries use server-side 8-second time-bucketed TTL caching to minimize server load.
